## Интерфейс IModule

Любой модуль системы должен реализовывать этот интерфейс, чтобы ядро (core) могло им управлять.

**1. Свойства модуля:**
*   `getId()` — уникальный строковый идентификатор (например, "rename").
*   `getName()` — человекочитаемое имя (например, "Переименование сканов").
*   `getVersion()` — версия модуля (например, "1.0.0").

Почему строка, а не enum: Использование enum создало бы жесткую связь между
ядром и конкретными модулями. Ядро не должно пересобираться при добавлении
нового модуля. Строка обеспечивает слабую связанность (loose coupling) и
позволяет подключать модули динамически

**2. Выполнение задачи:**
*   `execute(Параметры)` — главный метод. Ядро передает ему параметры (пути к файлам/папкам). 
*   Модуль возвращает статус (Успешно / Ошибка) и текст сообщения (для лога).

**3. Параметры для модуля rename:**
*   `excelPath` — путь к файлу спецификации.
*   `scansFolder` — путь к папке со сканами.
